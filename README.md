# Recipe Flavor Algebra

**Category:** Food & Culinary Tools

Define ingredients as 7-dimensional flavor vectors (umami, heat, acidity, sweetness, richness, bitterness, saltiness). Compose recipes by combining ingredients with quantity weights. Visualizes the blended flavor profile as a radar chart and finds "flavor bridges" — ingredients from other cuisines with similar profiles using cosine similarity. Pre-loaded with 10 common ingredients. All data persists in localStorage.
